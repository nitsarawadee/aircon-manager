ของ **INTERLINK Telecom**

## เริ่มใช้งาน

```bash
npm start     # เปิดเซิร์ฟเวอร์ที่ http://localhost:8787
npm test      # รันเทสต์ทั้งหมด
```

**ไม่ต้องติดตั้งอะไรเพิ่ม** ไม่ต้อง `npm install` ไม่ต้องมีบัญชีของบริการภายนอก
ไม่ต้องมีคีย์ และไม่ต้องต่ออินเทอร์เน็ต ขอแค่มี Node.js 22 ขึ้นไป
กับไฟล์ฐานข้อมูลที่ `data/aircon.db`

ค่าตั้งค่าทุกตัวไม่ใส่ก็ได้ ดูตัวอย่างที่ [.env.example](.env.example)

## ระบบนี้ประกอบด้วยอะไร

```
web/index.html        หน้าเว็บทั้งหมดในไฟล์เดียว ไม่มีขั้นตอน build
src/                  ตรรกะทั้งหมด — ห้ามรู้จักแพลตฟอร์ม
  api.js              ทะเบียนคำสั่งที่หน้าเว็บเรียกได้
  context.js          สิทธิ์ ล็อก และเครื่องมือที่ platform ส่งเข้ามา
  schema.js           ชื่อตาราง/คอลัมน์ + รายการตรวจเช็ค 21 ข้อ
  db/                 อ่าน/เขียน SQLite + เติมคอลัมน์ที่ขาดตอนเปิดเซิร์ฟเวอร์
  modules/            ตรรกะรายหน้า (แผน ประวัติ งานซ่อม เอกสาร งบประมาณ ผู้ใช้)
platform/             ส่วนเดียวที่รู้จัก Node
  node.js             เซิร์ฟเวอร์ HTTP + ต่อสายทุกอย่างเข้า src/
  photos.js           เก็บรูปถ่ายประกอบเอกสารลงดิสก์
  docs.js             เก็บไฟล์ PDF ของเอกสารลงดิสก์
  attachments.js      เก็บไฟล์เอกสารที่ช่างถ่ายส่งมาลงดิสก์
  pdf-render.js       สั่ง Chrome/Edge ในเครื่องแปลงเอกสารเป็น PDF
  backup.js           สำรองฐานข้อมูลอัตโนมัติ
scripts/              สคริปต์บำรุงรักษา — ดูผลก่อนได้ ต้องใส่ --apply ถึงเขียนจริง
test/                 เทสต์ทั้งหมด รันด้วย npm test
data/                 ฐานข้อมูล ไฟล์สำรอง รูปถ่าย และไฟล์เอกสาร (ไม่ขึ้น git)
```

**หน้าเว็บคุยกับเซิร์ฟเวอร์ทางเดียว** — `POST /api/call` พร้อม `{token, fn, args}`
ชื่อ `fn` ต้องอยู่ในทะเบียนของ `src/api.js` เท่านั้น

## กติกาของโปรเจกต์นี้

1. **ไม่พึ่ง npm เลยสักตัว** ใช้เฉพาะของที่มากับ Node (`node:sqlite`, `node:test`)
2. **`src/` ห้ามรู้จักแพลตฟอร์ม** อะไรที่ต้องแตะไฟล์หรือสั่งโปรแกรมอื่น ต้องอยู่ใน `platform/`
3. **ทำงานได้โดยไม่ต้องออกเน็ต** ฟอนต์ ไอคอน โลโก้ และไฟล์ทุกชนิดอยู่ในเครื่องหมด
4. **ฐานข้อมูลห้ามขึ้น git** เป็นข้อมูลจริงของบริษัท
5. **แก้ฐานข้อมูลได้แค่เพิ่มคอลัมน์** ห้ามลบ ห้ามเปลี่ยนชื่อ ห้ามเปลี่ยนชนิด
6. **คอมเมนต์และข้อความทั้งหมดเป็นภาษาไทย** อธิบาย "ทำไม" ไม่ใช่ "ทำอะไร"

เหตุผลของแต่ละข้ออยู่ใน [docs/CONTEXT.md](docs/CONTEXT.md)

## ประวัติ

เดิมระบบนี้รันบน Google Apps Script โดยใช้ Google Sheets เป็นฐานข้อมูล
ซึ่งช้าจนกระทบการใช้งานประจำวัน (2-4 วินาทีต่อคลิก)

ตอนนี้ย้ายมาเป็นเว็บแอปปกติที่ใช้ SQLite และ**ไม่เหลือส่วนใดที่พึ่ง Google อีกแล้ว**
ทั้งฐานข้อมูล การสร้าง PDF และการเก็บไฟล์เอกสาร ทำในเครื่องที่รันระบบทั้งหมด

บันทึกการย้ายเก็บไว้ที่ [docs/project-summary.html](docs/project-summary.html)
(เป็นเอกสารย้อนหลัง ไม่ได้อธิบายระบบปัจจุบัน)
