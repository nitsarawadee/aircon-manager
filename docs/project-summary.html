ย้ายระบบจัดการแอร์ออกจาก Google Apps Script

ระบบบริหารจัดการเครื่องปรับอากาศของ INTERLINK Telecom เดิมรันบน Google Apps Script ซึ่งช้าจนกระทบการใช้งานประจำวัน โปรเจกต์นี้ย้ายระบบหลังบ้านออกมาเขียนใหม่ทั้งหมด โดยยังใช้ Google Sheets เป็นฐานข้อมูลเหมือนเดิม ผู้ใช้ไม่ต้องเรียนรู้อะไรใหม่ และข้อมูลเดิมไม่ต้องย้าย

2ครั้ง คุยกับ Google ต่อ 1 คำสั่ง
เดิม 20-30 ครั้ง

237 Node ใน 69 จังหวัด

0บาท ค่าใช้จ่ายที่เพิ่มขึ้น

ผลลัพธ์ที่วัดได้

ตัวเลขฝั่ง "ใหม่" มาจากการวัดจริงกับข้อมูลชุดปัจจุบัน (457 เครื่อง) ส่วนฝั่ง "เดิม" อ้างอิงจากประสบการณ์ใช้งานจริงของทีม ไม่ได้วัดด้วยเครื่องมือ

หัวข้อเดิม (Apps Script)ใหม่
จำนวนครั้งที่คุยกับ Google ต่อ 1 คำสั่ง 20-30 ครั้ง 2 ครั้ง วัดแล้ว
เวลาตอบสนองต่อการกด 1 ครั้ง 2-4 วินาที 0.5-1 วินาที วัดแล้ว
เวลาเปิดหน้าเว็บครั้งแรก 3-6 วินาที ต่ำกว่า 1 วินาที
ไลบรารีภายนอกที่ต้องติดตั้ง — 0 ตัว

ข้อจำกัดที่ต้องพูดตามตรง

เวลาตอบสนองยังไม่นิ่ง บางครั้งพุ่งถึง 4-5 วินาที ซึ่งตรวจสอบแล้วว่า ไม่ได้เกิดจากโค้ดของเรา — ระบบยิงไปหา Google แค่ 2 ครั้งต่อคำสั่งเสมอและไม่มีการเขียนข้อมูลแอบแฝง แต่ Google Sheets API เองตอบไม่คงที่ วัดได้ตั้งแต่ 0.5 ถึง 5.9 วินาทีสำหรับคำขอเดียวกัน

ถ้าต้องการความเร็วที่นิ่งกว่านี้ ทางแก้คือย้ายฐานข้อมูลจาก Google Sheets ไปเป็นฐานข้อมูลจริง ซึ่งโครงสร้างที่วางไว้รองรับการเปลี่ยนนี้อยู่แล้ว

สิ่งที่ทำ

เขียนระบบหลังบ้านใหม่ทั้งหมด 3,711 บรรทัด แทนของเดิมที่เป็น Apps Script 2,375 บรรทัด ส่วนหน้าเว็บ 4,233 บรรทัดใช้ของเดิมเกือบทั้งหมด แก้เฉพาะจุดที่ติดต่อกับเซิร์ฟเวอร์

สิ่งที่หายไปจาก Apps Script และสิ่งที่มาแทน

ของเดิมของใหม่เหตุผล
SpreadsheetApp ตัวเชื่อม Google Sheets API ที่เขียนเอง ทำงานแบบอ่านทีเดียว เขียนทีเดียว แทนการแตะชีตทีละช่อง
CacheService ที่เก็บ session ในตัวระบบ เก็บลงไฟล์ด้วย รีสตาร์ทแล้วผู้ใช้ไม่หลุด
LockService คิวกันเขียนข้อมูลชนกัน เข้าคิวรอได้จริง ไม่ต้องวนถามซ้ำ
ตัวแปรส่วนกลาง ข้อมูลแยกตามคำขอ ป้องกันข้อมูลผู้ใช้รั่วข้ามคนเมื่อมีคนใช้พร้อมกัน

ความสามารถที่เพิ่มเข้ามา

ปริ้นฟอร์มเปล่า

เลือก Node แล้วได้ PDF ที่เติมชื่อ Node, Serial, Asset, BTU ให้อัตโนมัติ ช่องตรวจเช็คเว้นว่างให้ช่างเขียนหน้างาน

แนบเอกสารแล้วปิดงาน

ถ่ายรูปฟอร์มที่เขียนมือส่งกลับมา แนบไฟล์แล้วระบบปิดงานในแผน ลงประวัติ และคิดงบให้ในขั้นตอนเดียว

ปิดงานหลายเครื่องพร้อมกัน

หนึ่ง Node มีแอร์ 2 ตัว ล้างพร้อมกันแล้วแนบเอกสารใบเดียว ปิดงานได้ทั้งคู่ โดยกรอกค่าล้างแยกรายเครื่อง

รันได้ทั้งบนเครื่องและบนคลาวด์

โค้ดชุดเดียวกัน ย้ายขึ้นเซิร์ฟเวอร์บริษัทได้โดยไม่ต้องแก้ตรรกะ เปลี่ยนแค่ไฟล์ตั้งค่า

ข้อบกพร่องที่ตรวจพบและแก้ไปแล้ว

ส่วนใหญ่เป็นความผิดพลาดแบบ "เงียบ" คือระบบไม่ฟ้อง error แต่ข้อมูลผิด ซึ่งอันตรายกว่าระบบล่มเพราะกว่าจะรู้ตัวก็ตอนที่รายงานออกมาเพี้ยนแล้ว

ข้อมูลผิด

ฟอร์มบันทึกว่า "ตรวจแล้วปกติ" ทั้ง 21 ข้อ ทั้งที่ช่างไม่ได้แตะ

ช่องตรวจเช็คตั้งค่าเริ่มต้นไว้ที่ "ปกติ" ทำให้เอกสารทุกใบอ้างว่าตรวจครบทุกข้อโดยอัตโนมัติ เป็นปัญหาด้านความน่าเชื่อถือของเอกสาร ไม่ใช่แค่เรื่องการแสดงผล

ระบบล่ม

เพิ่มคอลัมน์ใหม่แล้วทุกเมนูใช้งานไม่ได้ทั้งระบบ

ระบบสั่งเขียนข้อมูลก่อนขยายความกว้างของชีต Google จึงปฏิเสธคำสั่ง และเนื่องจากการตรวจโครงสร้างชีตทำงานตั้งแต่คำสั่งแรก ความผิดพลาดจุดเดียวจึงทำให้ทุกเมนูพังพร้อมกัน

ตัวเลขเพี้ยน

ค่า BTU 36,000 และค่าล้าง 30,000 บาท กลายเป็นวันที่

Google Sheets ส่งวันที่กลับมาเป็นตัวเลขล้วน ซึ่งช่วงตัวเลขนั้นทับกับค่าที่ระบบใช้จริงพอดี แก้โดยระบุชัดว่าคอลัมน์ไหนเป็นวันที่ แทนการเดาจากขนาดตัวเลข

รายงานผิด

รายการของวันที่ 1 ถูกนับเข้าเดือนและปีก่อนหน้า

เซิร์ฟเวอร์ทำงานด้วยเวลามาตรฐานสากล ต่างจาก Apps Script ที่ใช้เวลาไทย ทำให้กราฟแนวโน้มและรายงานงบประมาณคลาดเคลื่อน

ความปลอดภัย

ปิดบัญชีผู้ใช้แล้วยังใช้งานต่อได้อีก 6 ชั่วโมง

ระบบเดิมต้องรอ session หมดอายุเอง ตอนนี้ตัดการใช้งานทันทีเมื่อปิดบัญชีหรือรีเซ็ตรหัสผ่าน

สถานะปัจจุบัน

เสร็จ ระบบหลังบ้านใหม่ทำงานได้ครบทุกเมนู รายการเครื่อง · แผนล้างแอร์ · ประวัติ · งานซ่อม · ฟอร์มล้างแอร์ · งบประมาณ · จัดการผู้ใช้
เสร็จ ชุดทดสอบอัตโนมัติ 8 ข้อ ผ่านทั้งหมด ครอบคลุมการแปลงวันที่และตัวเลข ซึ่งเป็นจุดที่เคยผิดพลาดมาแล้ว 2 ครั้ง
กำลังทำ ทดสอบอยู่กับสำเนาของข้อมูลจริง ยังไม่สลับไปใช้ไฟล์จริง ทีมจึงยังทำงานบนระบบเดิมได้ตามปกติโดยไม่กระทบ
รอ ย้ายขึ้นเซิร์ฟเวอร์บริษัท ตอนนี้รันบนเครื่องผู้พัฒนา ย้ายได้โดยคัดลอกโฟลเดอร์แล้วสั่งรัน ไม่ต้องแก้โค้ด
รอ เปลี่ยนวิธีเก็บรหัสผ่าน ปัจจุบันเก็บเป็นข้อความธรรมดาตามระบบเดิม ควรเปลี่ยนเป็นแบบเข้ารหัสก่อนเปิดให้เข้าจากภายนอก โค้ดรองรับไว้แล้ว

ค่าใช้จ่าย

ไม่มีค่าใช้จ่ายเพิ่มจากเดิม และไม่ต้องผูกบัตรเครดิตกับบริการใด
