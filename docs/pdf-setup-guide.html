ตั้งค่าให้ฟอร์มล้างแอร์ออกไฟล์ PDF ได้

ตอนนี้ระบบบันทึกข้อมูลได้ครบทุกอย่างแล้ว เหลือแค่ส่วนที่แปลงฟอร์มเป็นไฟล์ PDF ซึ่งต้องไปตั้งค่าฝั่ง Google แยกอีกที่หนึ่ง ทำครั้งเดียวจบ

ใช้เวลาราว 15 นาที ทำครั้งเดียว 7 ขั้นตอน
ทำไมต้องมีขั้นตอนนี้

ไฟล์ PDF ของฟอร์มล้างแอร์ถูกสร้างด้วยวิธีพิเศษ คือให้ Google วาดตารางลงในสเปรดชีตก่อน แล้วสั่งพิมพ์ออกมาเป็น PDF วิธีนี้ทำให้หน้าตาตรงกับฟอร์มกระดาษเป๊ะและได้ 1 หน้าเสมอ แต่มีแค่ Google เท่านั้นที่ทำได้ ระบบของเราจึงต้องส่งงานส่วนนี้ไปให้ Google ทำแทน

สิ่งที่กำลังจะทำคือ สร้างผู้ช่วยตัวเล็กๆ ไว้ฝั่ง Google แล้วบอกระบบของเราว่าให้ติดต่อผู้ช่วยตัวนี้เวลาต้องการไฟล์ PDF

เก็บหน้านี้ไว้กับตัว

หน้านี้มีรหัสลับของระบบอยู่ในขั้นตอนที่ 3 อย่าส่งลิงก์นี้ให้คนนอกทีมนะครับ

1

สร้างที่ทำงานให้ผู้ช่วยตัวใหม่

  1. เปิดแท็บใหม่ในเบราว์เซอร์ ไปที่ script.google.com
  2. ถ้ามันให้เข้าสู่ระบบ ให้ล็อกอินด้วยบัญชี Google เดียวกับที่เป็นเจ้าของไฟล์ Google Sheet
  3. กดปุ่ม โปรเจกต์ใหม่ New project — อยู่มุมซ้ายบน
→ ควรเห็นอะไร หน้าจอแก้ไขโค้ดสีขาว มีข้อความสั้นๆ อยู่กลางจอประมาณว่า function myFunction() { } — นั่นคือโค้ดตัวอย่างที่ Google ใส่มาให้
2

วางโค้ดของผู้ช่วยลงไป

  1. เปิดโฟลเดอร์ C:\Project Aircon-manager\apps-script ในเครื่อง
  2. คลิกขวาที่ไฟล์ PdfService.gs เลือก เปิดด้วย แล้วเลือก Notepad
  3. กด Ctrl+A เพื่อเลือกทั้งหมด แล้ว Ctrl+C เพื่อคัดลอก
  4. กลับไปที่แท็บ Apps Script กดในช่องโค้ด แล้วกด Ctrl+A ตามด้วย Ctrl+V
→ ควรเห็นอะไร โค้ดตัวอย่างของ Google หายไป แทนที่ด้วยโค้ดยาวๆ ที่มีคอมเมนต์ภาษาไทยอยู่เต็มไปหมด บรรทัดบนสุดจะเป็นกรอบดาวจันทร์ที่เขียนว่า "บริการสร้าง PDF ฟอร์มล้างแอร์"
3

แก้ 2 บรรทัดในโค้ด

หาบรรทัดที่ขึ้นต้นว่า const SHARED_SECRET (อยู่ประมาณบรรทัดที่ 33) แล้วลบทั้งบรรทัดทิ้ง เอาบรรทัดนี้ไปวางแทน

บรรทัดที่ 1 ที่ต้องแก้ — รหัสลับ 
const SHARED_SECRET = 'ดูค่าจาก PDF_SERVICE_SECRET ในไฟล์ .env';

จากนั้นหาบรรทัด const SPREADSHEET_ID (อยู่ประมาณบรรทัดที่ 50) ลบทิ้งแล้ววางบรรทัดนี้แทน — นี่คือ ID ของชีตสำเนาที่คุณใช้ทดสอบอยู่

บรรทัดที่ 2 ที่ต้องแก้ — ชีตที่ใช้ 
const SPREADSHEET_ID = 'ดูค่าจาก SPREADSHEET_ID ในไฟล์ .env';

เสร็จแล้วกดไอคอน รูปแผ่นดิสก์ ด้านบนเพื่อบันทึก (หรือ Ctrl+S)

ระวังตรงนี้

ต้องมีเครื่องหมาย ' ครอบข้อความ และมี ; ปิดท้ายบรรทัด ถ้าคัดลอกจากกล่องด้านบนทั้งบรรทัดจะได้ครบอยู่แล้ว ไม่ต้องพิมพ์เอง

4

ขออนุญาตให้ผู้ช่วยเข้าถึงไฟล์ของคุณ

ผู้ช่วยตัวนี้ต้องสร้างไฟล์ PDF ลง Google Drive ของคุณ Google เลยต้องให้คุณอนุญาตก่อน

  1. ที่แถบด้านบน มีช่องเลือกชื่อฟังก์ชัน กดแล้วเลือก setupPermissions
  2. กดปุ่ม เรียกใช้ Run ข้างๆ กัน
  3. จะมีหน้าต่างเด้งขึ้นมาขอสิทธิ์ กด ตรวจสอบสิทธิ์ Review permissions
  4. เลือกบัญชี Google ของคุณ
จุดที่คนติดกันเยอะที่สุด

จะมีหน้าจอเตือนขึ้นมาว่า "Google ยังไม่ได้ยืนยันแอปนี้" (Google hasn't verified this app) พร้อมสัญลักษณ์เตือนสีเหลือง หน้าตาน่ากลัวเหมือนโดนไวรัส

ไม่ต้องตกใจ ไม่ได้ผิดอะไร — Google ขึ้นแบบนี้กับสคริปต์ทุกตัวที่คนเขียนใช้เอง เพราะยังไม่ได้ส่งให้ Google ตรวจสอบเพื่อขายเป็นสินค้า ซึ่งเราไม่ได้จะทำอยู่แล้ว

วิธีผ่าน: กด ขั้นสูง Advanced ที่มุมล่างซ้าย แล้วกดลิงก์ข้างล่างที่เขียนว่า ไปที่ ... (ไม่ปลอดภัย) Go to ... (unsafe) จากนั้นกด อนุญาต Allow

→ ควรเห็นอะไร กลับมาที่หน้าโค้ด และมีแถบดำๆ โผล่ขึ้นมาด้านล่างเขียนว่า "อนุญาตสิทธิ์และสร้างแม่แบบฟอร์มเรียบร้อย พร้อมใช้งานสร้าง PDF แล้ว" ถ้าเห็นข้อความนี้คือผ่านแล้ว
5

เปิดให้ระบบของเราติดต่อผู้ช่วยได้

ตอนนี้ผู้ช่วยพร้อมทำงานแล้ว แต่ยังไม่มีที่อยู่ให้ติดต่อ ต้องเผยแพร่ก่อน

  1. มุมขวาบน กดปุ่มสีน้ำเงิน ทำให้ใช้งานได้ Deploy
  2. เลือก การทำให้ใช้งานได้ใหม่ New deployment
  3. ด้านซ้ายมีไอคอนเฟือง กดแล้วเลือก เว็บแอป Web app
  4. ตั้งค่า 2 ช่องนี้ให้ตรงเป๊ะ:
    • ดำเนินการในฐานะ Execute as → เลือก ฉัน Me
    • ผู้ที่มีสิทธิ์เข้าถึง Who has access → เลือก ทุกคน Anyone
  5. กด ทำให้ใช้งานได้ Deploy
เรื่อง "ทุกคน" ที่อาจทำให้กังวล

การเลือก "ทุกคน" ไม่ได้แปลว่าใครก็เปิดดูข้อมูลแอร์ของคุณได้ มันแค่เปิดช่องให้ระบบของเราส่งข้อความไปหาผู้ช่วยได้เท่านั้น และผู้ช่วยจะทำงานให้เฉพาะคนที่รู้รหัสลับในขั้นที่ 3 — ซึ่งมีแค่ระบบของคุณที่รู้

จำเป็นต้องเลือก "ทุกคน" เพราะระบบของเราไม่ได้ล็อกอินบัญชี Google ถ้าเลือกอย่างอื่นผู้ช่วยจะไม่ยอมรับงาน

→ ควรเห็นอะไร หน้าต่างแจ้งว่าเผยแพร่สำเร็จ พร้อมกล่องข้อความยาวๆ ที่ขึ้นต้นด้วย https://script.google.com/macros/s/ และลงท้ายด้วย /exec — กดปุ่มคัดลอกข้างๆ กล่องนั้นไว้ เดี๋ยวต้องใช้
6

บอกที่อยู่ผู้ช่วยให้ระบบรู้

  1. เปิดโฟลเดอร์ C:\Project Aircon-manager
  2. หาไฟล์ชื่อ .env (ชื่อขึ้นต้นด้วยจุด ไม่มีนามสกุล) คลิกขวา → เปิดด้วย → Notepad
  3. เลื่อนลงล่างสุด จะเจอ 2 บรรทัดที่ยังว่างอยู่ ให้แก้เป็นแบบนี้
2 บรรทัดล่างสุดของไฟล์ .env 
PDF_SERVICE_URL="วางลิงก์ที่คัดลอกมาจากขั้นที่ 5 ตรงนี้"
PDF_SERVICE_SECRET="ดูค่าจาก PDF_SERVICE_SECRET ในไฟล์ .env"

บรรทัดแรก ให้ลบข้อความภาษาไทยข้างในเครื่องหมายคำพูดออก แล้ววางลิงก์ที่คัดลอกมาแทน โดยยังคงเครื่องหมาย " ครอบไว้ทั้งสองข้าง

เสร็จแล้วกด Ctrl+S เพื่อบันทึก แล้วปิด Notepad

7

เปิดระบบใหม่แล้วลองใช้

ระบบอ่านไฟล์ตั้งค่าตอนเปิดครั้งเดียว ต้องปิดแล้วเปิดใหม่ถึงจะรู้จักค่าที่เพิ่งใส่

  1. กลับไปที่หน้าต่างดำๆ ที่ระบบรันอยู่
  2. กด Ctrl+C เพื่อหยุด
  3. พิมพ์คำสั่งข้างล่างแล้วกด Enter
เปิดระบบใหม่ 
npm start

จากนั้นเปิดหน้าเว็บ ไปที่เมนู ฟอร์มล้างแอร์ แล้วลองกดบันทึกฟอร์มใหม่อีกครั้ง

→ ควรเห็นอะไร บันทึกสำเร็จโดยไม่มีข้อความสีแดง และมีลิงก์ไฟล์ PDF ให้กดเปิดดูได้ ลองกดดูว่าหน้าตาตรงกับฟอร์มกระดาษไหม
รายการเก่าที่บันทึกไปแล้ว

ฟอร์มที่บันทึกไปตอนที่ยังตั้งค่าไม่เสร็จ ไม่ต้องกรอกใหม่ครับ ในตารางฟอร์มล้างแอร์จะมีปุ่มให้สร้าง PDF ย้อนหลังได้เลย

ถ้าไม่เป็นไปตามนั้น

ยังขึ้นข้อความเดิมว่า "ยังไม่ได้ตั้งค่าบริการสร้าง PDF"

แปลว่าระบบยังอ่านค่าใหม่ไม่เจอ ลองไล่ดู 3 อย่างนี้

1. ปิดแล้วเปิดระบบใหม่หรือยัง — แค่บันทึกไฟล์ .env เฉยๆ ไม่พอ ต้องกด Ctrl+C แล้วสั่ง npm start ใหม่

2. ไฟล์ที่แก้ชื่อ .env จริงไหม บางทีตอนบันทึก Notepad เติม .txt ต่อท้ายให้โดยไม่บอก ลองเปิดโฟลเดอร์แล้วดูว่ามีไฟล์ชื่อ .env.txt โผล่มาหรือเปล่า ถ้ามีให้เปลี่ยนชื่อกลับเป็น .env

3. ลิงก์ยังมีเครื่องหมายคำพูดครอบอยู่ทั้งสองข้างไหม

ขึ้นว่า "รหัสลับไม่ถูกต้อง"

รหัสในขั้นที่ 3 กับขั้นที่ 6 ไม่ตรงกัน มักเกิดจากตอนคัดลอกติดช่องว่างมาด้วย หรือคัดลอกไม่ครบตัว

วิธีที่ชัวร์ที่สุดคือกดปุ่ม "คัดลอก" จากกล่องในหน้านี้ทั้งสองที่ อย่าพิมพ์เอง

ขึ้นว่า "บริการสร้าง PDF ตอบกลับมาในรูปแบบที่อ่านไม่ได้"

เกือบทุกครั้งเกิดจากตอนเผยแพร่ในขั้นที่ 5 เลือก "ผู้ที่มีสิทธิ์เข้าถึง" ไม่ใช่ ทุกคน / Anyone

กลับไปที่ Apps Script กด ทำให้ใช้งานได้ → จัดการการทำให้ใช้งานได้ Manage deployments → กดไอคอนดินสอเพื่อแก้ไข → แก้ช่องนั้นให้เป็น "ทุกคน" → บันทึก

แก้โค้ดใน Apps Script แล้ว แต่ระบบยังใช้โค้ดเก่า

Apps Script ไม่ได้เอาโค้ดล่าสุดไปใช้อัตโนมัติ ต้องสั่งเผยแพร่ใหม่ทุกครั้งที่แก้

กด ทำให้ใช้งานได้ → จัดการการทำให้ใช้งานได้ → ไอคอนดินสอ → ช่อง "เวอร์ชัน" เลือก ใหม่ New version → บันทึก

ทำแบบนี้ลิงก์เดิมจะใช้ได้ต่อ ไม่ต้องไปแก้ไฟล์ .env ใหม่

PDF ออกมาแล้ว แต่ไม่มีโลโก้ หรือหน้าตาเพี้ยน

แม่แบบฟอร์มอาจสร้างไม่สมบูรณ์ ให้สร้างใหม่

ใน Apps Script เลือกฟังก์ชัน buildCleaningFormTemplate แล้วกด เรียกใช้ จากนั้นลองสร้าง PDF อีกครั้ง

จะเปลี่ยนไปใช้ชีตตัวจริงตอนไหน

เมื่อทดสอบจนพอใจแล้ว ให้ทำ 3 อย่าง

1. แชร์ชีตตัวจริงให้ ดูค่าจาก GOOGLE_SERVICE_ACCOUNT_EMAIL ในไฟล์ .env เป็นผู้แก้ไข

2. แก้ SPREADSHEET_ID ในไฟล์ .env เป็น ID ของชีตตัวจริง แล้วเปิดระบบใหม่

3. ส่วน SPREADSHEET_ID ใน Apps Script จะเปลี่ยนหรือไม่เปลี่ยนก็ได้ เพราะใช้เป็นกระดาษทดวาดฟอร์มเท่านั้น ไม่ได้อ่านข้อมูลจากชีตนั้น

ทำครบแล้วเป็นอันจบ

หลังจากนี้ไม่ต้องกลับมาทำอีก ผู้ช่วยฝั่ง Google จะทำงานให้ตลอด ยกเว้นกรณีเดียวคือถ้ามีการแก้โค้ดใน Apps Script ต้องสั่งเผยแพร่ใหม่ทุกครั้ง (ดูหัวข้อ "แก้โค้ดแล้วแต่ระบบยังใช้โค้ดเก่า" ด้านบน)
